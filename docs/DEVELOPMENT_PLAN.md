## 2. Current Technical Structure

- Frontend: React and Vite.
- Styling: Tailwind CSS.
- Routing: React Router.
- Content: JavaScript data modules.
- Documents: public/assets/documents.
- Images: public/images.
- Documentation: docs.
- Version control: local Git repository initialized.

The application currently operates as a frontend portfolio. No database, authentication system or CMS is required for its current scope.

## 3. Completion Requirements

A task is considered complete only when:

1. Its implementation is present in the project.
2. Relevant available checks pass.
3. Content is supported by supplied or verified evidence.
4. Outstanding limitations are documented.
5. Browser-dependent behaviour is tested where possible.

Unverified qualifications, publications, awards, employment details and other professional claims must not be invented.
