# Dr. Linus Uche Emeanulu — Academic Portfolio

A professional academic portfolio presenting biography, research interests, verified publications, teaching, professional experience, education, and contact information.

## Project Status

The six-page portfolio is implemented and has passed the production build and initial browser review.

## Technology Stack

- React 18
- Vite 5
- Tailwind CSS 3
- React Router 6
- JavaScript and JSX

## Website Pages

| Page | Route |
|---|---|
| Home | `/` |
| About | `/about` |
| Research & Publications | `/research` |
| Teaching & Supervision | `/teaching` |
| Experience & Education | `/experience` |
| Contact | `/contact` |

## Legacy URL Redirects

- `/publications` → `/research`
- `/cv` → `/experience`
- `/events` → `/research`
- `/articles` → `/research`

## Features

- Responsive desktop and mobile navigation.
- Research and publication search and filtering.
- Verified professional experience and education.
- CV viewing and download.
- Email and WhatsApp contact links.
- Academic and social profile links.
- Custom 404 page.

## Design Direction

Modern Scholar and Premium Editorial.

- Deep teal: `#123C3A`
- Accent green: `#3B8F70`
- White: `#FFFFFF`
- Light background: `#F4F7F6`
- Dark text: `#202927`
- Muted text: `#5F6B68`

## Getting Started

Requirements: Node.js 18 or later and npm.

Install dependencies:

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint

```
